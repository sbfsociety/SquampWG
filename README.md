# SquampWG
A platformer game set it the caves. Physics behind it in my other repo Squamp.

Even though it has same mechanics as Squamp, it has more features like:
  -Picture() 📷 - With provided extension, coordinate, scale and file name it loads them from assets and renders them onto the screen.
  -Text() 📝 - Just renders text lmao.
  -Rect() 📐 - Renders an oval shape for the finish and adds 1 to the ::gamestate, sets player's position to the next level's starting position.
  -Level() 🔦 - Just does the game loop so i don't have to type it ✍🏻 lmao .
